# vscode 로 gpt tts mp3 만들기
  vscode gpt-tts-mp3 폴더에 
    mkae_mp3.js 파일
      터미널에서 npm install openai
      터미널에서 node make_mp3.js / 하면 mp3 파일이 생성된다/
